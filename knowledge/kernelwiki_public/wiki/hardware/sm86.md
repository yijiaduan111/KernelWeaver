SM86 has up to 48 resident warps and 16 resident blocks per SM, with a 64K 32-bit register file. Shared memory capacity per SM is 100 KB; the per-block maximum is 99 KB. Dynamic allocations above the ordinary 48 KB limit require explicit opt-in, subject to device and function limits.

Ampere asynchronous global-to-shared copies can overlap data movement and computation. The required waits and buffer lifetimes still apply. Treat resource maxima as limits, not target occupancy or guaranteed best block sizes. Check the actual device before enabling any instruction path.
